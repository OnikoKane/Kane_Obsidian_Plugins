## 3. 当前功能（用户可见）

### 阅读视图题卡

- Markdown 中写 ```` ```zaptrace ```` 代码块，渲染成 Quiet Card。
- 单层 1px 边、无卡片阴影、无内层框。
- 标签顺序：`大科目 category` → `子科目 subject` → 章节/知识点 `tags`（最多显示 2 个 + `+N`）。
- 「答案与笔记」合并为一个 38px 折叠行，默认关闭。
- 折叠展开状态按题卡 `qid` 持久化到 `data.json` 的 `foldOpen`；下次打开保持。
- 展开后：答案 Markdown 渲染 + 个人笔记 textarea（保存/取消，Ctrl+Enter 保存，Esc 取消）。
- 个人笔记保存只更新目标 `zaptrace` 块的 `### 个人笔记` 节，题干与答案不动。
- 笔记最后记录时间：插件内保存后显示 `notesUpdatedAt`；历史上已有笔记但从未经插件保存过时，回退显示文件修改时间；无笔记不显示。
- 工具区：
  - `tags` 图标常驻；点击打开标签 popover。
  - 星标未收藏默认隐藏，hover/focus 出现；收藏后为实心 amber 星。
  - `⋯` 菜单：收藏/打开原文/复制题干。
- 星级点击成功后播放本地 Web Audio 短音效；失败静默。

### 题库工作台

- 页头：标题、总题数、搜索、随机练一题、分类设置、刷新、设置。
- 6 个状态 chips：全部题目/到期复习/已收藏/未练/需完善/错题。
- 筛选：大科目、子科目、排序、章节标签。
- 分段视图：题卡流 / 紧凑表格 / 独立复习。
- 题卡流：
  - 内容区 ≥1080px 时一行 3 卡；1024–1439 两列；<1024 单列（容器查询为主，媒体查询兜底）。
  - 每卡默认展开「答案与笔记」，可折叠、可就地编辑个人笔记。
  - 卡片工具区同样有 `tags` 编辑图标与星标。
- 练习抽屉：≥1440 右侧分栏；<1440 覆盖；<720 全屏。

### 分类与标签

- 分类层级数据语法（写在题卡头部）：

```zaptrace
category: 数学
subject: 高等数学
tags: 导数, 极限
source: 高等数学 第七版 p.86
---
### 题干
...
### 答案
...
### 个人笔记
...
```

- `category` = 大科目；缺省推断「数学」。
- `subject` = 子科目；缺省使用 settings/defaultSubject 或文件夹名。
- `tags` = 章节/知识点。
- 分类设置入口：
  - 工作台页头「分类设置」
  - Obsidian 设置 → ZapTrace → 「编辑分类」
- 分类设置面板可增删大科目与子科目，保存到 `data.json.settings.taxonomy`；首次会从现有题卡自动播种。
- 题卡内 `tags` 图标打开的是 **popover 下拉**，不是 modal：
  - 大科目 select：只能从已配置分类中选
  - 子科目 select：随大科目联动
  - 标签 chips：可新增/移除；可自由输入新标签
  - 保存只改目标题卡头部的 `category/subject/tags`
- 大科目与子科目 chip 同色（accent-soft/accent），章节标签保持中性色。

## 4. 数据与持久化边界

### Markdown 是内容真源

- 题干、答案、个人笔记、AI 笔记都在题目所在 Markdown 的 ```` ```zaptrace ```` 代码块内。
- 插件只在用户明确操作时写 Markdown：
  1. 插入题卡模板（用户主动）
  2. 保存个人笔记（只改 `### 个人笔记` 节）
  3. 标签 popover 保存（只改头部 `category/subject/tags`）
- 其它内容严禁改写。

### `data.json`

`data.json` 保存：
- `schemaVersion: 1`
- `questions[qid]`：学习状态、`star`、`step`、`due`、`reviews`、`notesUpdatedAt`、可选 `foldOpen`
- `reviewLog`
- `settings`：主题、默认科目、卡文件夹等
- `settings.taxonomy`：分类配置（`{ categories: [{name, subjects[]}], seeded }`）

说明：
- `category` 是纯派生，不写入 `questions` 状态。
- `notesUpdatedAt`：ISO 本地时间或 null。
- `foldOpen`：未设置时阅读卡默认关闭、题库卡默认展开；用户手动开合后写入显式 true/false。
- 不要手动改 `data.json`；测试前先备份。

## 8. 已知问题 / 接班注意

1. **标签输入未按 Enter 直接点保存可能丢失**：`tagPopover` 当前把输入框内容在 Enter 时才加入 `tags`，若用户输入新标签但不按 Enter 就点保存，可能不保存这个草稿。下一版建议在 `doSave` 前吸收 `input.value.trim()` 并加入 tags。
2. **分类 panel 的草稿比较用 JSON.stringify**：未知字段顺序不同可能误判「有修改」；影响小。
3. **旧 `src/view/metadataModal.ts` 是 v3.1 dead code**：v3.2 已改用 `tagPopover.ts`；文件未删，不进入最终 UI。可在确认后删除。
4. **note 时间 fallback 使用整篇文件 mtime**：已有笔记没有 `notesUpdatedAt` 时显示的是文件最后修改时间，不是“笔记节最后修改时间”。这是只读回退，用户明确要求“无笔记无时间”。
5. **跨实例折叠状态**：同一 qid 同时渲染在阅读卡和题库卡时，另一边不实时同步，刷新后一致；状态已即时写入 data.json。
6. **vault 中有验收夹具**：`E:\NoteCache\zt-v3-fixture.md` 仍存在（验收用，不是正式笔记）；`data.json` 可能包含夹具状态。删除前必须向用户确认，并先备份 `data.json`。
7. **不要动** `ZapTrace/examples/zaptrace-demo.md` 的未提交修改；它是用户的。
8. **不要使用 Agent Team**：本轮用户已明确要求先不使用团队，直接改文件/命令即可。
9. 不包含 PDF 导入、批注、AI 调用；这些是后续功能，不在当前范围。
