# Annotation Marker（ZCode 版）

给 Obsidian 的 Markdown 笔记加**高亮 / 批注 / 注音**，并且**不改动原笔记正文**：
所有标注写进插件目录自己的“影子副本”，打开「标注模式」时渲染这份副本，退出时再把正文同步回原笔记。

本仓库是 [Annotation Marker](https://github.com/) 3.0.18 的**本地改造分支**，由 **ZCode** 维护，
在原版基础上修了一批数据安全与体验问题（清单见 [PATCHES.md](PATCHES.md)）。

> 插件 id 仍然是 `annotation-marker`，所以你原来的设置与标注文件可以直接沿用。

---

## 功能

- **彩色高亮 + 批注**：选区标注，10 种可选颜色，批注内容存在标注标签里，不改正文。
- **注音（ruby）**：给标注文字加注音，默认收成一行，点开才展开编辑。
- **跨段标注**：跨多个列表项 / 段落的标注会按段渲染，共用同一个标注 id。
- **全文标注**：一次性给整段内容打标注。
- **标注视图**：右上角「标注模式」按钮进入，固定为「阅读 + 标注」；退出时回到原来的阅读/编辑模式。
- **批注列表**：右下角入口图标，面板跟随图标移动，支持排序、跳转、右键菜单。
- **侧边栏管理**：`标注管理` 视图，按当前笔记/全部浏览、搜索、查看详情。
- **导入 / 导出**：可导入旧版标注数据，可把当前笔记的标注导出成文件。
- **双向同步**：原笔记与标注副本之间的改动用字符级 diff 合并，标注不会因为外部编辑而丢失。

### 本分支修掉的问题（摘要）

| 问题 | 处理 |
| --- | --- |
| 编辑模式下标注菜单抢 `mouseup`，让其他插件的选区工具失效 | 标注交互只在阅读模式生效 |
| 外部编辑后，批注内容被正文覆盖 | 合并前后恢复 `data-annotation-note` |
| 极端情况下合并把全部高亮抹掉 | 检测到「有→零」直接放弃写回并告警 |
| 在标注视图里再点标注模式，生成套娃文件 | 识别自身文件并转为关闭 |
| 标注视图里相对路径图片「找不到」 | 重定向 `getFirstLinkpathDest` 的 `sourcePath` |
| 标注视图顶部标题变成「目录&.文件名」 | 假文件 `basename` 换回原笔记名 |
| 开/关标注视图时图片「突然变大再回落」 | 布局就位前隐藏图片 + 过渡窗口打标 |
| 滚到中间再开/关会跳回顶部 | 按可见容器读滚动位置 + 标题锚点按帧校正 |

完整 32 项见 [PATCHES.md](PATCHES.md)。

## 安装

手动安装（推荐，避免被上游版本覆盖）：

1. 下载本仓库 `AnnotationMarker_zcode/` 下的 `main.js`、`styles.css`、`manifest.json`；
2. 放到 `<你的仓库>/.obsidian/plugins/annotation-marker/`；
3. 重启 Obsidian（或 `Ctrl+R`），在「设置 → 第三方插件」启用 **Annotation Marker**。

> **关于版本号**：本分支的 `version` 是 `99.0.0`，高于上游任何版本，
> Obsidian 的插件更新检查因此不会再提示更新，也就不会覆盖本地补丁。
> 如果你希望恢复跟随上游更新，把 `manifest.json` 的 `version` 改回上游版本号即可（但补丁会丢失）。

## 快捷键

命令 `Annotation Marker: 启动/关闭标注模式` 常驻在「设置 → 快捷键」里，可自行绑定。
另外还提供：打开/关闭标注管理侧边栏、导入旧数据、导出当前笔记标注、按颜色标注选中文本（颜色 1–10）。

---

## 兼容性

- 需要 Obsidian **1.12.7+**，桌面端与移动端均可（`isDesktopOnly: false`）。
- 本分支的额外样式都挂在 `body.mubu-style` 下：如果你的 Obsidian 没有这个类名，
  它们不会生效，插件功能不受影响（只是外观回到原版）。
- 与 Adjustable Media 的图片布局块有专门的兼容处理（见 PATCHES.md 第 20 / 31 项）。

## 数据存放

标注文件放在插件目录下，和笔记路径一一对应：

```
.obsidian/plugins/annotation-marker/annotations/
└── <笔记相对路径，/ 换成 &.>.md
例：Adjustable Media 指南/使用指南.md
 →  annotations/Adjustable Media 指南&.使用指南.md
```

插件通过注入 `vault.fileMap` + `metadataCache` 把这份副本“伪装”成普通笔记来渲染，
并在文件树、最近文件等枚举接口里把它隐藏起来。**不要手动编辑这些文件**：
它们跟原笔记之间是字符级双向同步的。
